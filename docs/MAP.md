# 지도 구현 결정

사용자가 제공한 `UI.pdf`의 지리형 대한민국 지도에 맞춰 전국·시군구 화면은 정적 SVG를 사용한다. 이 기본 화면에는 외부 지도 SDK·API 키·실시간 타일 요청이 필요하지 않다. 여행 상세의 실제 장소 지도만 OpenStreetMap 타일을 사용한다.

| 층 | 현재 동작 |
|---|---|
| 시·도 | 17개 경계와 지역명, 클릭/키보드 선택. 하위 지역 기록을 합산해 방문 시·도를 대표 사진 썸네일로 채움 |
| 시·군·구 | 시·도 선택 후 250개 경계를 확대 표시하고 클릭/키보드 선택. 방문 지역을 대표 사진 썸네일로 채움 |
| 읍·면·동 | 시·군·구 화면에서 3,627개 행정 읍·면·동의 방문 상태와 기록을 탐색 |
| 검색 | 시·도, 시·군·구, 읍·면·동 이름 및 전체 지역명 검색 |
| 장소 | DAY별 자유 입력 또는 명시적 Photon 검색. 선택 결과의 OpenStreetMap 좌표를 저장하고 상세 화면에 번호 핀으로 표시 |

새 기록은 읍·면·동 또는 시·군·구 단위로 저장한다. 읍·면·동 기록은 상위 시·군·구와 시·도 방문 상태에 합산하며 가장 최근 기록(`mostRecentTripForRegion`, 시작일 기준)의 사진으로 지역을 채운다. 한 지역의 여러 기록은 지역 화면에서 사진별 카드로 분리한다. 사진 핀과 지역명 위치는 행정구역 도형의 표시 중심점이며 여행 장소의 실제 좌표라고 주장하지 않는다. V4 이전 시·도 단위 기록과 기존 시·군·구 기록은 그대로 보존한다.

읍·면·동 목록은 행정안전부의 `행정기관(행정동) 및 관할구역(법정동) 변경내역(2026.3.25. 시행)` 중 행정동 코드를 사용한다. 현재 번들 경계가 2026년 7월 행정구역 개편 이전 기준이므로 같은 시점의 3월 자료를 채택했고, 전북 코드와 부천·화성 일반구는 기존 지도 폴리곤의 상위 코드로 정규화했다. `scripts/generate-neighborhoods.py`로 원본 XLSX에서 프런트 JSON과 Flyway V7을 함께 재생성한다.

## 사진으로 지역 채우기

2026-10-19 결정. PRD의 "내 사진으로 채워지는 지도"를 위해 방문 지역은 원형 핀이 아니라 지역 모양 전체를 사진으로 채운다. 구현은 `frontend/src/KoreaMap.tsx`, 도형 계산은 `frontend/src/mapShape.mjs`, 판정 테스트는 `frontend/tests/map-shape.test.mjs`다.

- **채우는 방법**: 지역 경계 path를 `clipPath`로 써서 기록의 썸네일(긴 변 320px)을 자르고 `preserveAspectRatio="xMidYMid slice"`로 빈틈 없이 덮는다. 시·도는 경계 칠하기와 같은 evenodd 규칙으로 잘라 경기 안의 서울 자리를 비운다. 사진이 아직 오지 않았거나 실패하면 기존 방문 색(시·도 `#E5E5E2`, 시·군·구 `#D9D9D4`)이 보인다. 사진이 경계선 안쪽 절반을 덮으므로 시·도 외곽선은 사진 위에 다시 그리고, 시·군·구 경계는 원래대로 사진 위 층에 있다.
- **사진 상자**: 사진은 지역 전체 경계 상자가 아니라 가장 큰 고리(본토·본섬)의 경계 상자에 맞춘다. 전체 상자를 쓰면 경북은 울릉도·독도(x 579~687, 전국 viewBox는 545까지), 인천은 백령도(x −39)까지 상자가 늘어나 본체에는 사진의 일부만 보인다. 본체 상자 밖의 작은 섬은 방문 색으로 남는다. 섬으로만 된 시·군·구(예: 신안군)는 가장 큰 섬에 사진 중심이 온다.
- **원형 핀을 남기는 기준**: 지역 면적의 제곱근(같은 면적 정사각형의 한 변)이 그 지도의 사진 핀 지름보다 작으면 채우기와 함께 핀을 표시한다. 그보다 작은 지역은 채운 사진이 핀보다 작게 보여 무엇인지 알아보기 어렵다. 전국 지도(핀 지름 66)에서는 서울·부산·대구·인천·광주·대전·울산·세종·제주 9곳(√면적 24~47)이 핀을 쓰고 경기·강원·충북·충남·전북·전남·경북·경남 8곳(97~152)은 채우기만 쓴다. 시·군·구 지도(핀 지름은 라벨 크기의 2.9배, 화면에서 약 14~23px)에서는 250곳 중 63곳(경기 25, 경북 12, 인천 9, 부산 5 등)이 핀을 쓴다. 면적은 고리별 신발끈 공식의 부호 있는 합이다.
- **전국 핀 모양**: 바깥 반지름을 39에서 33으로 줄이고 지역명 알약을 사진 아래쪽 안으로 넣었다. 이전 크기와 사진 아래 이름표로는 서울 핀이 미방문 "경기" 라벨과, 광주 핀이 "전남" 라벨과 겹쳤다. 핀은 맨 마지막에 그려 이웃 라벨이 사진을 가리지 않는다. 세종·대전은 표시점이 35 단위로 가까워 둘 다 방문하면 핀이 겹친다(이전에도 같았다). 시·군·구 핀 크기는 그대로이며, 작은 방문 시·군·구는 이전처럼 라벨 자리에 핀만 보여 주고 이름은 `title`·aria-label·아래 목록으로 제공한다.
- **지역명 라벨**: 사진 위의 지역명은 `#111111` 알약 배경(시·도 78%, 시·군·구 72% 불투명)에 흰 글자로 둔다. 미방문 라벨은 바꾸지 않았다.
- **접근성**: 지역마다 경계를 감싼 그룹 하나가 버튼이며 이름과 "방문/추천 여행지/미방문" 상태를 aria-label로 읽고 Enter·Space로 선택한다. 전국 핀은 같은 시·도를 여는 마우스 보조 영역이라 `aria-hidden`이고 탭 순서에 넣지 않는다. 이전에는 방문 시·도가 경계와 핀으로 탭 순서에 두 번 있었다. 초점·호버 때 사진을 80% 불투명도로 낮추고 초점에는 검정 윤곽선을 그린다.
- **범례와 색**: 시·군·구 화면의 "방문" 견본은 그 시·도에서 가장 최근 기록의 썸네일로 채우고, 기록이 없으면 기존 회색이다. 추천·미방문 색 구분은 바꾸지 않았다.

경계 원본은 [KnellBalm의 대한민국 행정구역 GeoJSON](https://github.com/KnellBalm/kr-admin-geojson)이다. 이 저장소는 국가공간정보포털(V-World)의 2023-07-29 경계를 WGS84로 재투영·단순화했고, 17개 시·도와 250개 시·군·구 파일을 제공한다고 설명한다. 앱은 이를 다시 좌표 변환·경량화해 `frontend/src/map/boundaries.json`으로 보관한다. 데이터 출처 표시는 화면 하단과 이 문서에 남긴다. 향후 경계 갱신 시 지역 코드와 기존 여행 기록의 연결을 먼저 확인해야 한다. 예를 들어 원본 강원특별자치도 코드는 `51`이고 앱의 기존 내부 코드는 `42`라 표시 단계에서 매핑한다.

가공 스크립트는 `scripts/generate-map.py`다. 재생성하려면 원본 저장소의 `ctprvn.geojson`과 `sig.geojson`을 각각 `tmp/map/provinces.geojson`, `tmp/map/districts.geojson`으로 내려받아 실행한다. `tmp` 원본은 배포 파일이 아니다.

장소 검색은 입력할 때마다 자동 호출하지 않고 사용자가 검색 버튼을 누를 때만 Photon 공개 서버를 호출하며, 같은 실행 중 동일 검색어는 캐시한다. 한국 영역으로 결과를 제한하고 검색 결과의 이름·주소·위도·경도·OSM 식별자를 저장한다. 공급자 URL은 빌드 환경변수로 교체할 수 있다. 상세 지도는 저장 좌표를 모두 포함하도록 Web Mercator 확대 수준을 계산하고 필요한 OpenStreetMap 타일만 요청한다. 두 화면 모두 OpenStreetMap 출처 링크를 표시한다. 공개 서비스는 SLA가 없으므로 상용·대규모 배포 전 자체 Photon 또는 계약된 검색/타일 공급자로 교체하고 이용량·캐시·개인정보 정책을 확정해야 한다. DAY별 이동 경로와 GPS 추적은 구현하지 않는다.
