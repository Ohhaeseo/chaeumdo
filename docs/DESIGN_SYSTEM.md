# 채움도 디자인 시스템

기준은 사용자가 제공한 `UI.pdf`와 5개 색상, S-Core Dream OTF다. PDF의 가느다란 글자, 여백, 둥근 사진 영역, 단색 선과 세로 흐름을 모바일 화면에 맞췄다. 원본 PRD의 기능은 유지하되 사용자가 후속 요청한 계정 화면을 추가했다.

## 색상

| 토큰 | 값 | 사용 |
|---|---|---|
| 배경 | `#F7F7F5` | 앱 바탕, 추천 시·도 |
| 글자 | `#111111` | 본문, 강조, 주요 버튼 |
| 표면 | `#FFFFFF` | 카드, 입력, 하단 탭 |
| 보조 | `#696973` | 보조 글자, 시·도 경계 |
| 구분 | `#E5E5E2` | 구분선, 시·군·구 경계, 입력 테두리 |

사진 자체 색상만 예외다. 그림자·모달 배경은 위 색의 투명도로 만든다. 방문 지도에는 실제 대표 사진 마커를 올리고 추천 미방문은 밝은 바탕으로 구별한다. 상태를 색만으로 전달하지 않도록 지역명과 접근성 이름을 제공한다.

## 글꼴과 비율

S-Core Dream 원본 OTF를 self-host한다. 300·400·500·600 굵기를 선언하고 폰트 변환은 하지 않는다. 기본은 가는 300~400, 핵심 버튼과 기록명은 400~500이다. 모바일 제목 23~24px, 로그인 제목 40px, 본문 11~14px, 보조 9~11px을 쓴다. 글꼴 로드 실패 시 sans-serif로 대체한다. 원본 라이선스 이미지를 폰트와 함께 배포한다.

## 화면 구조

화면 폭은 최대 390px이며 큰 화면에서는 가운데 정렬한다. 기준 모바일 높이는 844px, 아래로 긴 상세·폼은 자연스럽게 스크롤한다. 지도와 나 화면에만 2개 하단 탭이 있다. 뒤로 가기가 있는 화면에서는 탭을 감춘다.

| 화면 | PDF를 반영한 구조 | 동작 |
|---|---|---|
| 로그인/회원가입 | 중앙 제목, 둥근 입력과 검정 알약 버튼 | 로그인, 가입, 아이디·비밀번호 찾기, 기기 체험 |
| 시작 화면 | 채움도 이름과 한국 지도 아이콘을 중앙에 배치 | 초기 계정·기록 로딩 동안 표시 |
| 지도 | 상단 제목·검색·더보기, 전국 및 시·군·구 확대 지도, 사진 마커, 안내 문구, 추가 버튼, 2개 탭 | 시·도 선택, 시·군·구 선택, 지역 검색, 기록 추가 |
| 지역 | 큰 둥근 대표 사진, 지역명·짧은 설명, 추가 버튼, 사진 기록 목록 | 기록 상세로 이동 |
| 기록 상세 | 대표 사진, 동행자, DAY별 장소, 수정 버튼, 더보기 | 수정, 삭제 확인 |
| 기록 상세 | 대표 사진, 동행인 원형 아바타, DAY 세로 타임라인·장소 카드, 수정 버튼 | 기록 확인·수정 |
| 기록 폼 | 지역 선택, 대표 사진 업로드, 동행인, 시작·종료일, DAY별 장소, 저장 | 날짜별 장소 추가·삭제, 장소마다 작은 사진 선택·교체·삭제와 미리보기 |
| 나 | 원형 아바타, 방문 지역·여행 횟수·여행 일수, 계정 버튼 | 로그아웃·계정 삭제 |
| 완료 | 중앙 아이콘·완료 문구·지도 복귀 버튼 | 저장 후 지도 확인 |

## 요소·상태

- 주요 버튼은 높이 약 43px, 검정 바탕·흰 글자, 둥근 끝이다. 작은 카드·입력은 흰 바탕과 얇은 테두리를 쓴다.
- 사진은 `object-fit: cover`로 영역을 채운다. 실제 사진이 없으면 이미지 아이콘을 보여 준다. 사용자 사진을 임의 샘플 사진으로 대체하지 않는다.
- 장소 카드 오른쪽 사진 영역은 31px 정사각형이다. 사진이 없으면 추가 아이콘을 보이고, 선택하면 같은 크기 썸네일로 교체한다. 기존 장소 사진은 기록 수정 시 유지되며 별도 삭제할 수 있다.
- 지도 시·도 경로는 클릭과 Enter/Space로 확대 지도를 연다. 확대 지도에서는 시·군·구 경로도 같은 방식으로 선택할 수 있으며, 모든 지역은 하단 목록과 검색으로도 접근한다.
- 입력은 이름 또는 접근성 레이블을 갖는다. 오류는 문장과 `role=alert`로 표시한다. 키보드 초점은 검정 윤곽선이며 모션 감소 설정을 따른다.
- 날짜는 포함 일수로 계산하고 역전 날짜를 거부한다. DAY 입력은 현재 기간만 저장한다.
- 동행자 `+`는 이름 입력을 하나씩 추가한다. 각 항목은 삭제할 수 있고, 저장 후 상세 화면에 원형 아바타로 표시한다.
- 복구 코드는 가입·비밀번호 변경 후 한 번만 표시한다. 삭제는 비밀번호 재확인 대화상자로 시작한다.
- 기록 삭제는 상세 화면의 더보기에서 시작하며 지역·날짜와 사진 정리 범위를 확인한 뒤 실행한다. 취소를 기본 안전 경로로 제공한다.
